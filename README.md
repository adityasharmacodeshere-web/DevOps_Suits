# Develop With Us

The event site for **DevOps Club, Bennett University** — a one-day build room taking place on October 1, 2026.

## Local run

This is a static HTML/CSS/JavaScript site with no build step or backend. Open `index.html` directly in a browser, or serve the folder with any static server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Structure

- `index.html` — semantic event page and registration form
- `styles.css` — responsive editorial visual system
- `script.js` — launch transition, cursor, parallax, tilt, reveal, and client-side form state
- `assets/` — reserved for future verified/licensed assets

The Harvey Specter treatment is intentionally a CSS silhouette and typographic signature. No unverified promotional photography or copyrighted stills are bundled. Registration is client-side only.
